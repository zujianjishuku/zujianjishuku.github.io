Football GD Archive

A private, owner-operated utility for archiving football match data files to Google Drive and verifying their integrity.

This website provides information about the application only. It does not serve as a login portal, upload endpoint, or public archive.

What the application does

  • Archives the owner's football match data files into an application-managed Google Drive folder.
  • Uses Google Drive API with the limited drive.file permission.
  • Checks uploaded files through download and SHA-256 integrity verification.
  • Runs as a private utility operated by the Google account owner, not as a consumer-facing cloud service.

Privacy and permissions

The application requests only the Drive file access needed for its archiving workflow. It does not request blanket access to unrelated Drive files. Google authorization credentials are kept on the operator's private system.

See the Privacy Policy and Terms of Use.
